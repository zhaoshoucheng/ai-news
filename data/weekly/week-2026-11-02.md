# AI 模型与 API 变更周报

**周报周期：2026-11-02 至 2026-11-06**

## 本周概览

本周没有检测到结构化模型清单中的新增、下线或参数变更，但多个官方更新带来了值得开发者关注的模型与 API 能力变化。OpenAI 发布面向授权网络安全工作的 GPT-6 Cyber，并推出 GPT-Image-2.6 系列，新增 SVG、GIF 生成及标记辅助编辑；Anthropic 为 Messages API 引入可减少重复上下文传输的 **Message Threads** Beta，并公告 Opus 4.8 快速模式将于 11 月 30 日移除；Google 则发布 Gemini Omni 1.2 Flash 视频生成与编辑能力，同时下调视频输出价格 30%。此外，Gemini 2.5 Pro 已进入弃用流程，需尽早安排迁移。

> **本周重点行动：**尽快规划 Gemini 2.5 Pro 迁移；在 11 月 30 日前处理 Claude Opus 4.8 快速模式依赖；评估 Gemini Omni 1.2 Flash 和 OpenAI 图像 API 的新能力，并验证其在现有工作流中的成本与效果。

## OpenAI

### 模型与 API 更新

#### GPT-6 Rosalind：面向生命科学研究的专用模型

OpenAI 于 10 月 30 日发布 **GPT-6 Rosalind**，定位于复杂生命科学研究，提供专业生物推理和科学工具使用能力。访问仅向通过 Rosalind Research 可信访问计划审核的组织开放，供获授权用户开展内部研究。

**开发者影响与建议**

- 这是受限访问的研究模型，不应视为可普遍调用的通用模型。
- 如业务涉及生命科学研究，可评估其专业推理与工具调用是否适合现有流程，并确认组织是否具备访问资格。
- 上线前应为研究类输出设置领域专家审核和适用的合规流程。

#### GPT-6 Cyber：授权网络安全工作流

OpenAI 于 11 月 5 日发布 **GPT-6 Cyber**，用于调查漏洞、在授权测试环境中复现漏洞并验证修复。官方说明强调其围绕授权范围使用；API 更新还提示，首次请求前需完成 Daybreak setup。

**开发者影响与建议**

- 该模型面向安全测试及防御工作，不应将其用于未授权目标。
- 集成前先按官方要求完成 Daybreak 配置，并在工具层实施目标范围、身份权限和操作审计控制。
- 建议将漏洞调查、复现、修复验证拆成可审计的步骤，并由人工确认高风险操作。
- 周报数据没有提供 GPT-6 Cyber 与其他模型的基准测试或定价对比，不宜仅凭公告推断其效果或成本优势。

#### GPT-Image-2.6：图像生成与编辑能力扩展

OpenAI 发布 **GPT-Image-2.6 Sunburst** 和 **GPT-Image-2.6 Flare**，用于图像生成和编辑。API 更新提及以下能力：

- 可调节生成复杂度；
- 支持 SVG 生成及动画 GIF 生成；
- 为支持的 GPT Image 2.5 与 2.6 模型增加标记辅助编辑；
- 涉及 `v1/images/generations` 与 `v1/images/edits` 接口。

**开发者影响与建议**

- 如果应用需要可编辑的矢量图、动画素材或局部修改，可优先验证新能力能否替代现有图像处理链路。
- 对标记辅助编辑，应检查标记格式、区域定位精度及编辑后内容一致性，并为不符合预期的结果保留重试或人工修正路径。
- 当前数据未列出 GPT-Image-2.6 的价格变化；切换前应核对官方计费和复杂度参数的实际影响，并用代表性任务进行成本测试。

## Anthropic

### API 更新：Message Threads Beta

11 月 2 日，Anthropic 为 Messages API 推出 **Message Threads** Beta，使用请求头：

```http
message-threads-2026-08-12
```

启用后，对话状态保存在服务器端，后续请求只需发送新增消息，可减少重复上下文传输，并有望降低长对话和 Agent 循环中的首 token 等待时间。线程在最后一次请求后 **5 分钟过期**，并会在最后一次使用后 **不超过 1 小时删除**。官方说明称该功能可用于 Claude API，以及部分 Claude 云平台渠道。

**开发者影响与建议**

- 对多轮长对话或连续工具调用场景，可测试 Message Threads 是否能减少请求体大小和上下文重复传输。
- Beta 能力存在行为或接口调整的可能，建议通过功能开关接入，并保留不使用线程的备用路径。
- 线程状态由服务端维护，设计时应明确线程 ID 与用户、会话的绑定关系，避免错误复用造成上下文串线。
- 需要评估 5 分钟空闲过期对客户端重试、长任务和恢复流程的影响；任务可能跨越该窗口时，应准备重新建立线程或恢复对话的策略。

### 重要弃用：Claude Opus 4.8 快速模式

Anthropic 已弃用 **Claude Opus 4.8 的 fast mode**，并计划于 **2026 年 11 月 30 日**移除。移除后，对 `claude-opus-4-8` 设置 `speed: "fast"` 的请求将返回错误。官方建议迁移至 **Claude Opus 5.5** 以继续使用快速模式。

**开发者影响与建议**

- 立即搜索生产配置、客户端代码和重试逻辑中对 `speed: "fast"` 的依赖，并建立迁移清单。
- 在截止日期前对 Opus 5.5 做质量、延迟、吞吐量及成本回归测试；官方更新未提供本周可用的详细对比数据。
- 迁移过程中，避免仅替换模型字符串而不验证输出行为和参数兼容性。
- 建议在 11 月 30 日前完成灰度切换，并对因参数或模型不兼容导致的错误配置告警。

### 安全与管理能力

11 月 5 日的更新增加了 **组织 IP allowlist Beta**：管理员可配置 IPv4、IPv6 地址或 CIDR 范围，最多 1,000 条；来自名单外地址的受覆盖服务请求将被拒绝。该功能可降低泄露 API Key 被异地滥用的风险。

更新还提到可通过 Admin API 将 Claude Enterprise 组织成员从 Claude 全面登出；本周数据中的说明未包含完整适用范围与接口细节。

**开发者建议：**如组织有网络出口管控要求，可评估 IP allowlist，并先确认哪些服务和请求会受其覆盖，再逐步启用，避免合法流量因出口地址变化被拒绝。

### 其他公告

Anthropic 发布了关于使用 Claude 研究 vault particles 的科学研究文章；本周数据没有提供相应的 API 或模型变更细节。

## Google Gemini

### 重要弃用：Gemini 2.5 Pro

Google 于 11 月 2 日公告 **`gemini-2.5-pro` 已弃用**，且已无法在 Google AI Studio 中选择。自 **2026 年 12 月 1 日**起，发往该模型的 API 请求将自动路由至 **Gemini 3.8 Flash**，并按 Gemini 3.8 Flash 费率计费。官方建议在该日期前主动将模型字符串更新为 `gemini-3.8-flash`，并参考迁移指南。

公告列出的潜在破坏性变化包括：

- Function calling 行为及 `thought_signature` 校验相关变化；
- `thinking_level` 替代原有相关配置。

**开发者影响与建议**

- 不要依赖 12 月 1 日后的自动路由作为长期方案；路由变化可能同时改变输出行为和账单归属。
- 近期完成模型字符串迁移，并以真实生产请求覆盖 function calling、工具调用结果处理、签名校验及思考配置。
- 检查 SDK、服务端封装和配置中心中是否存在硬编码的 `gemini-2.5-pro`。
- 对迁移后的质量、延迟和费用分别做基准测试。当前周报数据未包含两款模型的质量对比，因此不能假定 Flash 在所有任务上等同于 Pro。
- 在切换期监控错误率、工具调用失败率和实际账单，必要时调整路由与降级策略。

### Gemini Omni 1.2 Flash：视频生成与编辑正式 GA

Google 于 11 月 5 日宣布 **Gemini Omni 1.2 Flash**（`gemini-omni-1.2-flash`）正式可用。核心能力包括：

- 最长 **15 秒**的视频生成；
- 对话式视频编辑，包括首尾帧插值及逐轮延长；官方更新说明相关片段时长为 3–10 秒，单轮延长后视频最长可达 30 秒；
- 可参考最多 6 张图片，提升角色与主体一致性；
- 付费层速率限制翻倍；
- 视频输出价格降低 **30%**，公告给出的价格为 **每 100 万 tokens 12 美元**。

**开发者影响与建议**

- 对短视频生成、迭代式编辑和多参考图生成场景，可开始评估正式版本，并与现有视频生成方案比较质量、时延和总成本。
- 定价按 tokens 计费；结合 15 秒输出能力评估成本时，应以实际请求的输出 tokens 和官方计量规则为准，不能直接把 30% 降幅等同于所有任务成本下降 30%。
- 注意“单次生成时长”和“多轮延长后的总时长”并非同一个限制；需按业务需要验证分段生成、编辑和拼接的效果。
- 虽然付费层速率限制翻倍，仍建议对批量生成做并发控制，并在接近限流时设计退避与重试策略。

### Gemini 3.8 Flash TTS：语音混音

Google 新增 **Voice remixing**：可用自然语言指令修改已有的预置或设计语音，并生成独立保存的新语音。可通过 `POST /v1beta/voices` 配合 `gemini-3.8-flash-tts` 创建 `voice_...` ID，也可在 Google AI Studio 中交互式混音；之后可使用 Gemini 3.8 Flash TTS 或 Flash-Lite TTS 合成语音。

**开发者建议：**

- 评估语音混音是否能改善品牌语音定制流程，并确认新生成语音 ID 的保存、复用与权限管理方式。
- 上线前验证不同指令下的音色稳定性和输出可控性；在本周提供的数据中未说明该能力的额外价格或可用范围差异，应查阅对应指南确认。

### 第三方评测：Gemini 4 Carbon

Artificial Analysis 发布了 Gemini 4 Carbon 的评测数据：

- **Low**：Intelligence Index 为 **54**；
- **Medium**：Intelligence Index 为 **58**；
- 同时公布了 Google 性能结果。

该信息来自第三方评测，不等同于 Google 官方模型发布或 API 可用性公告。可将其作为后续选型观察指标，但不建议仅凭单一指数决定生产模型；应结合自身任务、延迟、价格和工具调用表现进行验证。
