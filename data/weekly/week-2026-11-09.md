# AI 模型与 API 周报

**周期：2026-11-09 至 2026-11-13**

## 本周概览

本周最重要的变化集中在 Anthropic 和 Google：Anthropic 发布面向长程推理与 Agent 工作流的 Claude Fable 5.2，并推出可在自有基础设施运行的 Claude Managed Agents；Google 则连续发布 Gemini 4 Carbon、Gemini Decision 和 Gemini 4 Hydrogen，覆盖高强度推理、结构化决策与日常编码等不同场景。Google 还将 `gemini-embedding-2-preview` 切换至正式版模型名，开发者应更新调用配置。OpenAI 本周没有检测到模型或 API 变更，公告主要涉及企业采购、Codex 应用案例与产品生态。

> **数据说明：** 本周结构化模型清单未报告新增、下线或变更模型；下文所述新模型和功能来自各厂商的官方更新记录。部分公告摘要不完整，因此未提供的信息会明确标注为未知。

## Anthropic

### 新模型：Claude Fable 5.2 与 Claude Mythos 5.2

Anthropic 于 11 月 9 日发布：

- **Claude Fable 5.2**（`claude-fable-5-2`）：面向要求较高的推理和长程 Agent 工作。
- **Claude Mythos 5.2**（`claude-mythos-5-2`）：能力与 Fable 5.2 相同，但仅向通过 Anthropic 验证计划的组织开放，例如 Cyber Verification Program。

官方更新列出的共同规格：

| 项目 | Fable 5.2 / Mythos 5.2 |
|---|---|
| 上下文窗口 | 1M tokens |
| 最大输出 | 128K tokens |
| 思考模式 | 始终启用自适应思考 |
| 输入价格 | $8 / 百万 tokens |
| 输出价格 | $40 / 百万 tokens |

官方记录中提及旧版 Fable 5.1，但可用摘要未提供其完整规格和价格，**因此无法据此可靠比较 Fable 5.2 的价格涨跌或性能提升幅度**。第三方 Artificial Analysis 报告了 Fable 5.2 不同思考等级的 Intelligence Index：Low 54、Medium 56、High 62、Xhigh 62、Max 65。这些是第三方评测结果，不等同于厂商承诺，也不能单独代表特定任务上的表现。

### API、平台与合规更新

- **自托管 Claude Managed Agents**：11 月 12 日的更新称，组织可以在自有基础设施上运行整个 Managed Agents 服务，而不仅是自托管沙箱；Agent、会话及历史记录也存储在客户环境中。模型请求仍发送至所选择的模型提供方，默认是 Anthropic。该功能需联系 Anthropic 申请访问。
- **Compliance API 安全态势数据**：安全态势信息进入 Claude Enterprise 组织的 Beta 阶段。更新提到活动 Feed 会记录安全态势页面上的 attestation 变化，并提供 `GET /v1/compliance/organizations/{organization_id}/security_posture` 查询组织当前安全态势结果。详细字段、可用范围等应以最新 API 文档为准。
- **组织 IP allowlist**：更新摘要提到 Claude Console 支持配置组织 IP 白名单，处于 Beta 阶段。

### 开发者建议

1. **先做任务级评估，再决定是否迁移。** 对长上下文、复杂推理和长程 Agent 任务，可重点测试 Fable 5.2；测试时同时关注正确率、工具调用、延迟、输出长度和单次任务总成本。
2. **核算长输出成本。** 官方列出的输入、输出单价差异较大，且最大输出为 128K tokens。对可能产生长答案或多轮 Agent 输出的场景，建议增加输出预算、停止条件和成本告警。
3. **确认 Mythos 的资格限制。** 需要 Mythos 5.2 的团队应先确认是否符合验证要求，避免将其作为未经确认可普遍调用的生产依赖。
4. **评估自托管的责任边界。** 自托管有利于掌控 Agent 数据和运行环境，但模型请求仍会发往模型提供方。上线前需确认数据流、保留策略、访问控制和合规责任。
5. **将 Beta 合规功能视为需验证能力。** 在依赖安全态势 API 或 IP allowlist 前，确认其组织资格、接口字段与稳定性，并保留现有审计和访问控制措施。

## Google Gemini

### 模型与 API 发布

#### Gemini 4 Carbon GA

- 模型：`gemini-4-carbon`
- 状态：GA
- 定位：持续 Agent 编码、多模态知识工作、科学推理与网络安全防御。
- 价格：**2026 年 11 月 30 日前**介绍价为输入 $2 / 百万 tokens、输出 $10 / 百万 tokens。

官方更新未提供与旧模型的直接规格或价格对比。介绍价有明确截止日期，预算评估不宜假定该价格长期有效。

#### Gemini Decision 与 Decisions API

- 模型：`gemini-decision-1`
- 用途：对文本、图像、音频、视频和 PDF 执行快速、校准后的二元、类别或 rubric 决策。
- 公告强调可实现**零输出 tokens**。

这项 API 面向分类、筛选、评分等决策型工作流，不必将其等同于通用文本生成模型。现有更新摘要没有列出定价和速率限制，接入前应查阅官方 [Decisions API 指南](https://aistudio.google.com/docs/changelog)及对应的价格、配额信息。

#### Gemini 4 Hydrogen GA

- 模型：`gemini-4-hydrogen`
- 状态：GA
- 定位：兼顾速度与效率，面向日常编码和 Agent 工作流；官方称其可用于免费层，并给出付费价格。
- 价格：输入 $1.50 / 百万 tokens，输出 $7.50 / 百万 tokens。
- 思考等级：low、medium、high，以及新增的 **xhigh**。
- 其他：官方公告称其为 Antigravity Agent 的默认模型。

Artificial Analysis 公布的 Intelligence Index 为：Low 27、Medium 41、High 51、Xhigh 54。该指数可作为初步参考，但开发者应结合自身任务和调用成本进行验证。

**与 Carbon 的价格对照：**按本周公布的单价，Hydrogen 输入价格低于 Carbon 介绍价（$1.50 vs. $2），输出价格也更低（$7.50 vs. $10）。但两者定位不同，且 Carbon 价格为 11 月 30 日前的介绍价；不宜只凭单价或第三方综合指数决定模型选型。

### 迁移与产品动态

- **Embedding Preview 切换至正式版：**`gemini-embedding-2-preview` 自 2026 年 11 月 6 日起已弃用，API 请求会路由至 `gemini-embedding-2`，并按正式版价格计费。官方称正式版使用相同 API schema、定价和 embedding 空间，**不需要修改其他代码或重新建立向量索引**。建议仍显式更新模型字符串，避免继续依赖弃用别名。
- 其他公告包括 Gemini Intelligence 扩展到更多设备、Google 与 Adobe 的创意和生产力工具整合，以及 Google Cloud 面向医疗场景的 Gemini 产品。这些是产品与行业动态，并非本周列出的通用 Gemini API 接口变更。
- Google 宣布将 Gemini 4 Hydrogen 引入 Google Search；这属于搜索产品更新，不代表开发者 API 行为同步变化。

### 开发者建议

1. **按任务选择模型。** 对持续编码、复杂多模态知识工作等任务，可评估 Carbon；对日常编码和成本敏感型 Agent 场景，可优先试用 Hydrogen。对分类、审核、评分等结构化判断，可评估 Decisions API。
2. **验证思考等级的质量与成本。** Hydrogen 支持 xhigh 等思考等级。建议分别测量不同等级下的质量、延迟与成本，不要默认所有任务都需要最高思考等级。
3. **留意 Carbon 介绍价到期。** 在财务预测中单独标注 11 月 30 日这一价格节点，并在到期后复核正式价格。
4. **完成 embedding 模型名迁移。** 即使官方表示 API schema 与向量空间保持不变，也建议更新配置、监控实际账单，并用现有检索评测集确认迁移结果。
5. **先核实 Decisions API 的定价和限制。** 零输出 tokens 是接口使用特征，不足以推断总成本、计费单位或速率限制；上线前应确认适用价格和配额。

## 第三方评测观察

- Artificial Analysis 报告 Meta Muse Ember 在 Intelligence Index 上得分 36，并称其单任务成本较 Claude Haiku 5.5（max）低约三分之二。该信息属于第三方评测与成本比较，不是本周三家厂商的 API 更新。
- Fable 5.2 与 Hydrogen 的第三方指数已在对应厂商章节列出。评测分数适合作为筛选线索，生产决策应基于实际业务数据复测。
- Artificial Analysis 与 Google DeepMind 合作推出 Multimodal Knowledge Agent（MKA）评测，关注复杂视觉文件上的 Agent 知识工作。后续可用于比较模型在多模态文档任务中的表现。
