# AI 模型与 API 每周变更报告

**周期：2026-11-23 至 2026-11-27**

## 本周概览

本周没有检测到模型目录中的新增、下架或模型属性变更，但有几项值得开发者关注的产品更新：OpenAI 更新了 `chat-latest` 指向的模型，并发布面向医疗问题的 Responses API 模型配置；Anthropic 宣布 Claude Opus 4.5 将于 **2027 年 1 月 22 日**从 Claude API 退役，并调整企业分析 API 的统计口径；Google 则宣布 Genie 4 已正式发布，可通过 Interactions API 进行实时交互式世界生成。此次数据未提供可确认的模型新旧性能对比或上述产品的完整定价信息。

## OpenAI

### 模型与 API

- **更新 `chat-latest`（11 月 24 日）**  
  该别名快照已更新，指向 ChatGPT Plus、Pro、Business 和 Enterprise 用户可用的最新模型。OpenAI 明确建议生产环境使用 **GPT-6.2 系列**，并将 `chat-latest` 定位为测试 ChatGPT 最新改进的选择；其底层模型会定期更新。  
  **开发者影响：** `chat-latest` 是浮动指针，模型行为可能随更新变化。对需要稳定输出、可复现评测或严格变更控制的生产工作负载，优先使用明确的模型版本，并建立回归测试；不要将 `chat-latest` 视为固定模型快照。

- **推出医疗场景的 Responses API 配置（11 月 24 日）**  
  新配置包括 `gpt-6.2-astra-healthcare`、`gpt-6.2-sol-healthcare`、`gpt-6-astra-healthcare` 和 `gpt-6.1-sol-healthcare`。这些配置为临床问题提供专门的模型运行环境；启用网络搜索时，会检索专门的医学来源索引。  
  **开发者影响：** 医疗应用接入前应确认这些配置在目标账户和部署区域可用，并单独评估检索来源、引用质量和临床安全性。专用配置不等于临床验证或可替代专业判断。

### 官方公告与研究

- **GPT-6 系列的蛋白质设计能力（11 月 24 日）**：OpenAI 称模型可结合推理与代码设计蛋白质结构和序列，并报告了针对五个目标的实验室结合证据。这是研究与实验结果，不应直接外推为可在任意生物学任务中稳定复现的能力。
- **MedChemBench**：推出用于评估模型理解分子结构、结合实验依据推理及选择早期药物候选物的基准。可关注其评测方法和结果，避免仅用通用基准判断专业任务能力。
- **Perplexity and Intelligence**：讨论 perplexity 对 AI 模型进展衡量及建立共享评估方法的作用。
- **Combatting adversarial distillation**：介绍通过训练、安全防护、检测和执法等手段防止能力提取的多层策略。
- **Shirudo**：OpenAI 与 Cisco 推出开源 Linux 运行时，帮助团队在部署补丁期间保护运行中的系统。
- **客户案例**：Hebbia 报告 GPT-6 Astra 在金融研究中的来源覆盖、引用相关性和呈现质量有所提升；Richpanel 分享以 GPT-6 系列驱动客服自动化的实践；Intentful 和 Clay 介绍了 AI 助手及 ChatGPT/Codex 集成的应用。

## Anthropic

### 模型生命周期与迁移

- **Claude Opus 4.5 弃用通知（11 月 23 日）**  
  `claude-opus-4-5-20251101` 与 `claude-opus-4-5` 计划于 **2027 年 1 月 22 日**从 Claude API 退役；Anthropic 建议迁移至 **Claude Opus 5.5**。数据未提供 Opus 4.5 与 Opus 5.5 的性能或价格对比。

  **开发者建议：**
  1. 盘点代码、配置、提示词和部署流水线中对两个旧模型 ID 的引用。
  2. 尽早用 Opus 5.5 运行代表性任务评测，比较质量、延迟、成本及工具调用行为。
  3. 在退役前完成灰度迁移，并为模型切换保留回滚方案。
  4. 若通过 AWS 或 Google Cloud 使用模型，核对相应平台的退役日期和迁移安排；公告指出其他平台日期可能不同。

### API 与平台

- **Enterprise Frontier Safeguards（EFS）进入 Beta**：已在 Claude Platform、Claude Platform on AWS，以及由 Anthropic 管理的 Google Cloud Claude Models 上推出。数据未说明具体配置项或收费方式；有企业治理、安全防护需求的团队应查看平台文档并确认适用范围。
- **企业分析 API 的 Web Search 计数修复**：`web_search_count` 此前漏计 Claude 在聊天中使用的部分搜索，现在会包含这些搜索，因此统计值可能上升。Anthropic 指出新增计数主要来自 Chat 与 Cowork unified。
- **企业分析 API 的会话定义调整**：Chat 与 Cowork unified 中，会话现在按 UTC 日计算：当天首次成功运行 Bash 命令、创建文件或编辑文件时开始，并在当天结束。旧规则则与进入 Cowork 云端会话有关，且可能跨日延续。

  **开发者影响：** 如果将 `web_search_count` 或会话数用于成本归因、活跃度分析或内部 KPI，应记录口径变化，并避免将新旧时间段直接视为同口径数据。

## Google Gemini

### 模型与 API

- **Genie 4 正式发布（GA，11 月 19 日公告）**  
  Genie 4（`genie-4`）已通过 **Interactions API（v1beta）**提供实时交互式世界生成：
  - 支持流式输出 **24 fps、16:9 视频**，并提供同步 **48 kHz 立体声音频**。
  - 通过 **WebRTC 和 WebSockets**传输。
  - 可使用文本、16:9 参考图像或两者组合初始化世界，并通过 WASD、方向键和会话中的文本事件进行实时控制。
  - 面向付费层级提供。

  **开发者影响：** 这是实时、多模态交互工作负载，不只是普通文本或单次视频生成接口。接入时需评估长连接管理、输入事件处理、音视频同步和流式输出的端到端延迟，并确认 v1beta 接口的稳定性及生产限制。

- **定价**：公告摘要列出输入 token **每 100 万个 $1.50**、文本输出 token **每 100 万个 $9.00**、视频 **每 100 万个 $17.50**。由于原始摘要被截断，无法从本周数据确认视频计费单位或完整的计价说明；正式估算前请核对官方定价页面。
