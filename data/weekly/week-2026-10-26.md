# AI 模型与 API 变更周报

**周期：2026-10-26 至 2026-10-30**

## 本周概览

本周最重要的模型更新是 OpenAI 发布 **GPT-6.1 Terra**，主打视觉推理与计算机操作；第三方评测也公布了该模型不同推理档位的结果。API 方面，Google Gemini 对**付费新项目**启用请求默认存储，开发者需检查数据留存设置；Anthropic 则推出组织级用量与成本分析 API，并将 Messages API 和 Token Counting API 的最大请求体积提高至 128 MB。Anthropic 还发布了新的 API 版本及 SDK，其中 SDK 存在独立于 API 版本的破坏性变更，升级前应做兼容性验证。本周没有检测到模型下架或模型元数据变更。

> **口径说明：**下文以本周发布的内容为主。检测数据也包含本周才抓取到的 10 月 20—23 日公告；这类较早公告放在相关厂商章节的“补充”项中，并标明发布日期。第三方评测不等同于厂商官方公告。

## OpenAI

### 模型与评测

- **10 月 26 日：发布 GPT-6.1 Terra。**官方将其定位为高效模型，强调视觉推理、精确计算机操作和自然表达。变更记录显示，该模型可通过 `v1/responses` 和 `v1/chat/completions` 使用，并提供了提示与迁移指南。
- **第三方评测：**Artificial Analysis 给出的 Intelligence Index 分数为：Non-reasoning 33、Low 36、Medium 41、High 44、Xhigh 45、Max 48。该评测还称 Terra 推进了成本效率边界，但本次数据未提供可直接量化的价格或与旧模型的同口径分数对比，不能据此推断具体节省幅度。

**开发者建议**

1. 对计算机操作、视觉推理等场景，先将 Terra 纳入小流量 A/B 测试，并以任务成功率、延迟、重试率和单位任务成本评估是否替换现有模型。
2. 分别测试不同推理档位；评测分数随档位变化明显，实际表现与成本应结合业务任务验证。
3. 阅读官方迁移指南，确认所用 API 接口、工具调用和结构化输出行为；避免仅因模型名称更新就直接替换生产配置。

### API、定价与平台

- **服务层级控制（10 月 21 日）：**项目可在 Platform 设置中选择允许使用的 service tier；组织设置也可统一限制所有项目可用的层级。该变更可能影响请求能否使用特定服务层级。
- **12 小时提示缓存（10 月 20 日）：**Responses API 支持选择 12 小时 prompt caching，使共享指令、工具和上下文在更长时间内受益于缓存输入价格。**12 小时缓存写入费用为输入 token 价格的 2.5 倍**，是否划算取决于复用频率与缓存命中情况。
- **Decisions API GA（10 月 22 日）：**支持共享输入缓存、在单个问题指令中加入图像、通过 `input_json` 传入结构化数据；单次请求最多支持 400 个问题，较公开测试阶段的 200 个增加一倍。底层模型为 `gpt-6-luna`。
- **API credits（10 月 28 日）：**符合条件的 ChatGPT Pro 和 Business 订阅用户，可领取每月最多 500 美元的 API credits。需将拥有的 API organization 与 ChatGPT 账户关联；额度、资格与领取条件以官方说明为准。

**开发者建议**

- 采用 12 小时缓存前，按实际请求间隔估算缓存命中收益，并将更高的缓存写入成本纳入预算；不要默认延长缓存就一定能降本。
- 组织级服务层级限制可能覆盖项目预期配置。建议在变更组织设置后验证各项目请求，并处理可能出现的 service tier 错误。
- Decisions API 提升了单请求问题数上限，但增加批量规模也可能放大单次失败的影响；应评估超时、错误重试和部分结果处理逻辑。
- credits 属于账户权益，不应视为 API 单价下调；预算和成本监控仍应按实际计费规则执行。

## Anthropic

### API 与 SDK

- **API 版本 2026-10-21（10 月 21 日）：**Anthropic 发布新 API 版本，并更新多个语言 SDK 和 `ant` CLI，默认发送该 API 版本。官方公告指出，新版 SDK 和 CLI 还包含**不依赖 API 版本的破坏性变更**。
- **用量与成本分析 API Beta（10 月 29 日）：**新增组织级 `/v1/organizations/analytics/usage` 和 `/v1/organizations/analytics/cost` 端点，可查询 Claude Console 与 Claude Enterprise 组织的 token 用量和成本，并按模型、workspace、API key、用户或服务账号等维度筛选、分组。需使用公告指定的 beta header。
- **最大请求体积提高（10 月 28 日）：**Messages API 和 Token Counting API 的最大请求大小从 32 MB 提高至 128 MB。
- **Inference hooks GA（10 月 20 日）：**面向 Claude Enterprise 组织，由 Beta 转为正式可用。
- **User profiles 与组织 webhooks（10 月 20 日）：**新增 user profiles，可将 API 请求关联到终端用户，使某些安全处置可作用于单一终端用户而非整个组织；组织 webhooks 加入 Admin API Beta。两者主要面向平台、网关及企业管理场景。

**开发者建议**

1. 升级 SDK 前，先核对对应语言 SDK 的迁移说明，并检查重命名、参数、异常处理等潜在破坏性变化；将 SDK 版本升级和 API 版本升级分开测试，以便定位问题。
2. 用量与成本分析 API 仍处于 Beta，应将其用于监控、报表或对账时保留数据校验机制，不要在未经验证的情况下将其作为唯一结算依据。
3. 128 MB 上限扩大了大文件请求空间，但不代表所有业务都适合一次性上传大负载；建议评估传输耗时、失败重试成本与请求处理时限。
4. 多租户产品可评估 user profiles 是否适合用于终端用户归属与安全治理，并注意其对现有用户标识体系和审计流程的影响。

### 模型与云平台

- **Claude Models on Google Cloud（10 月 22 日）：**Anthropic 托管的 Claude API 可通过 Google Cloud 项目访问；访问控制由 Google Cloud IAM 管理，账单通过 Google Cloud Marketplace 处理。公告摘要还提到 Claude Opus 5.5 的 Fast mode 在该服务上可用。
- **开发者影响：**已有 Google Cloud 治理、采购或账单流程的团队，可评估该接入方式；需分别确认 API 功能、模型可用性、服务层级和计费配置，不应假设它与其他 Claude 接入渠道完全一致。

### 官方公告

- Anthropic 公布与美国总务管理局（GSA）的合作扩展，并发布面向科学研究机构的 AI for Science 扩展及药物研发相关进展。
- 其他较早发布、于本周检测到的内容包括 UK AISI 网络测试事件评估、Agent Skills 捐赠给 Agentic AI Foundation，以及形式化软件验证和代码攻击面缩减相关研究。它们主要是安全、研究或生态公告，并未在本次数据中对应新的 API 变更。

## Google Gemini

### API 与开发工具

- **Generate Content API 默认存储（10 月 26 日）：**付费层级的**新项目**使用 `generateContent`、`streamGenerateContent` 和 `batchGenerateContent` 时，默认请求存储设置变为 `store=true`，以匹配 Interactions API。已有项目保留当前设置。
- **退出存储：**可在单次请求中设置 `store=false`，也可在 Logs and Datasets 控制台设置中关闭 Generate Content API logging。
- **Gemini API CLI Beta（10 月 27 日）：**Google 发布 `gemini-api` CLI，定位为无状态、零依赖的命令行客户端，面向 AI coding agents、脚本和 CI pipeline。可通过 Interactions API 生成文本与媒体、分析文件，并运行 Gemini 托管 agent。

**开发者建议**

- **优先检查数据存储设置。**新建付费项目时，确认请求中是否包含敏感信息，并核实项目级控制台设置及 `store=false` 是否符合自身的数据治理要求。已有项目不应假设设置已自动改变。
- 将 CLI 接入脚本或 CI 前，先验证凭证注入、命令退出码、错误处理和输出格式，并按最小权限原则配置执行环境。

### 模型动态

- 本周数据未显示 Google 官方 changelog 发布新模型，但第三方 Artificial Analysis 于 10 月 28 日报告 **Gemini 4 Carbon** 成为其 Intelligence Index v5 榜首，并公布 High 档分数 **59**。该结论属于第三方评测，不应视为 Google 的官方发布公告，也不代表其在所有任务上领先。

## 第三方评测与行业观察

- Artificial Analysis 更新了 GPT-6.1 Terra 各推理档位的评测结果，并报告 Gemini 4 Carbon High 的 Intelligence Index 为 59。
- 该机构还称，GitHub Copilot Fusion 会在 Anthropic 与 OpenAI 模型之间进行编排，以平衡性能和成本；其编码 agent 评测结果略低于 Claude Opus 5.5，但任务成本约为后者的一半。该结论来自第三方评测，适合作为进一步测试的线索，而不是直接替代自有任务基准测试的依据。
