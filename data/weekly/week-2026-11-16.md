# AI 模型与 API 变更周报

**周期：2026-11-16 至 2026-11-20**

## 本周概览

本周最重要的变化集中在 OpenAI 与 Google：OpenAI 发布 **GPT-6.2 Astra / Sol**，并调整 Responses API 的对话状态处理，同时推出按后台任务时长计费的低价选项；Google 将 **Gemini 4 Neon** 推向 GA，并上线可帮助 Agent 按需发现工具的 Tool Retrieval 预览。Google 还发布了实时交互式世界生成模型 Genie 4。Anthropic 本周没有模型发布或下架，但新增 Linked billing Beta，并公布了自托管 Managed Agents 等平台能力。模型监测清单未报告新增、移除或变更模型条目；以下模型发布信息来自官方 API 更新公告。

---

## OpenAI

### 模型与 API

- **GPT-6.2 Astra 和 GPT-6.2 Sol 发布**
  - 官方定位：Astra 面向高难度推理和编码任务；Sol 面向日常编码与 Agent 工作流。
  - 两款模型均支持 **Responses API** 和 **Chat Completions**；**工具调用要求使用 Responses API**。
  - GPT-6.2 调整了 Responses API 在修改对话前缀时保留推理状态的方式，也调整了顶层 `instructions` 字段的处理行为。官方建议按迁移指南检查现有实现。
  - 官方表示两款模型提升专业输出、编码和计算机操作能力，并改善效率、降低成本；本次数据未提供与旧模型可直接比较的具体价格或性能数字。

- **Responses API 后台完成任务定价**
  - 公测支持选择 **2 小时**或 **8 小时**后台完成窗口。
  - 相对 Standard，模型 token 费率分别降低 **30%**和 **40%**。
  - 公告提及 GPT-6.2 Astra、GPT-6.2 Sol、GPT-6.1 Terra 和 GPT-6 Luna。具体可用范围及计费细节应以官方文档为准。

- **GPT-Live-1.1 与 Live 会话更新**
  - GPT-Live-1.1 改进多语言语音对话中的发音、口音一致性和转录。
  - GPT-Live-1 / 1.1 的 WebRTC 会话支持配置 **standby**：无活动时暂停推理，检测到用户发言后恢复，有助于降低空闲会话的资源消耗。
  - 官方还建议使用自然语言描述何时将任务委派给后端。

- **审核能力**
  - 获批组织可免费使用 `omni-moderation-csam-latest`，即 OpenAI CSAM 图像分类器，帮助优先筛查和安排人工审核。
  - 返回信号区分潜在 CSAM 与潜在 AI 生成 CSAM。该能力定位为审核辅助，不能替代人工判断。

### 重要官方公告

- **ChatGPT Wallet**：为 ChatGPT Work、Codex 和 dots 中的 Agent 提供经用户批准的购买能力，并沿用既有银行卡保护机制。
- **Self-hosted Claude Managed Agents**：不适用；此项属于 Anthropic。OpenAI 本周另有大量企业与行业公告，见下方。
- **科学研究与模型评估**：扩展 ChatGPT 学术研究者计划，为全球 20 万研究人员提供前沿模型访问；启动与 Apollo Research、METR、Transluce、Goodfire 合作的嵌入式评估，涉及对齐、安全防护和监控。
- **行业与生态合作**：宣布与 LVMH Media Division、Le Groupe Figaro 合作，让出版内容通过 ChatGPT 提供摘要或摘录；发布 ChatGPT for Sales 及 30 多个新增或扩展的合作伙伴插件；更新 ChatGPT for Healthcare，包含计算机操作 Agent、临床回答改进和医疗插件。
- **研究与工程进展**：介绍 GPT-6 Astra 在芯片设计中的应用；发布研究加速与前沿风险管理相关内容；介绍 Codex 驱动的 Performance Factory 如何帮助保持 ChatGPT 响应速度。
- **其他**：发布 ChatGPT for Academic Researchers 相关研究观察、Holiday Extras 与 Sumitomo Life 等客户案例，以及与英国 King’s Trust 的合作。

### 第三方评测

Artificial Analysis 报告 GPT-6.2 Astra 的 Intelligence Index 随推理档位从 **Low 46** 到 **High 60、Max / Xhigh 62**；GPT-6.2 Sol 从 **Low 41** 到 **High 55、Max 57**、Xhigh 56。该机构称 Astra 在其 Intelligence Index 中排名第二。此为第三方评测结果，并非官方承诺；不同任务的表现和成本仍需用开发者自己的评测集验证。

### 开发者建议

1. **优先验证 Responses API 迁移影响**：尤其测试修改对话前缀、延续推理状态和顶层 `instructions` 的场景，避免将旧行为假定为完全兼容。
2. **检查工具调用路径**：如使用 GPT-6.2 并依赖工具调用，应确认已接入 Responses API，而不是仅依赖 Chat Completions。
3. **评估后台窗口的成本与时延权衡**：适合可异步处理、对完成时限不敏感的任务；上线前应测试失败恢复、超时和用户体验。
4. **为 Live standby 做端到端验证**：重点检查暂停和恢复时的会话状态、首字延迟及计费表现。
5. **将 CSAM 分类结果接入审核队列**：保留人工复核和审计流程，不应仅凭模型信号自动作出高风险处置。

## Anthropic

### API 与平台

- **Linked billing Beta**
  - 使用 `user-profiles-billing-2026-10-01` Beta header。
  - 用户可将自己的 Claude 组织关联到第三方应用；应用在 `/v1/messages` 或 `/v1/chat/completions` 请求中设置 `billing_policy`，选择由哪一方承担费用。
  - 用户可在 Claude Console 设置应用消费上限或解除关联。
  - 公告摘要显示此功能适用于组织直接向 Anthropic 付费的客户；其他适用条件及完整行为需查阅官方文档。

- **Self-hosted Claude Managed Agents**
  - 可将完整 Managed Agents 服务部署在自有基础设施，而不仅是自托管执行沙箱。
  - Agent、会话及会话历史由客户侧存储；服务将模型请求发送至选定提供方，默认是 Anthropic。
  - 当前需联系 Anthropic 申请访问。

- **AI 文本水印说明**
  - Claude Opus 4.6、Opus 4.5、Sonnet 4.5 和 Haiku 4.5 在受支持平台上生成的文本带有 Anthropic 文本水印。
  - 若将 `temperature`、`top_p` 或 `top_k` 设置为非默认值，文本可能不带水印。需要依赖水印进行内容识别或合规处理的应用，应核实目标平台支持情况，并谨慎修改采样参数。

### 其他公告

Anthropic 宣布其首次公开募股定价。本周未检测到 Anthropic 模型新增、移除或版本变更。

### 开发者建议

- 若采用 Linked billing，明确设计 `billing_policy` 的默认值、费用归属提示、消费上限处理和用户解绑后的降级行为。
- 对受数据驻留或隐私要求约束的应用，可评估自托管 Managed Agents；申请前梳理模型请求仍会发送给选定提供方这一边界。
- 不要把文本水印视为所有请求、所有平台均稳定存在的来源证明。

## Google Gemini

### 模型与 API

- **Gemini 4 Neon GA**
  - 模型 ID：`gemini-4-neon`，面向复杂软件工程、知识工作和科学工作流。
  - 支持 low、medium、high（默认）和 xhigh 四种 thinking level；提供统一 **1M token 上下文窗口**，并支持最长 **1M token 输出解码**。
  - 定价：**输入 $3.00 / 1M tokens，输出 $15.00 / 1M tokens**；仅付费层可用。
  - Artificial Analysis 的评测分数为 low 44、medium 55、high 60、xhigh 61。该机构称，相比 Gemini 4 Carbon，Neon 的 Intelligence 有小幅提升，单位任务成本约低 **17%**；这是第三方评测口径，不等同于 API token 单价变化。

- **Tool Retrieval 预览**
  - Gemini API 新增 Tool Retrieval，可让 Agent 在大量工具中按需检索，官方目标是以更少 token 使用数百个工具。
  - 对工具定义很多、工具描述消耗上下文较大的 Agent 特别相关。当前为预览功能，需关注适用模型、调用方式和行为变更。

- **Gemini 3.5 Transcribe 更新**
  - `gemini-3.5-transcribe` 与 `gemini-3.5-transcribe-live` 新增语音驱动的编辑、改写和格式整理能力。
  - 可对口述内容或已有文本执行操作，已有文本通过 `source_text` 提供。需依据对应的 Audio transcription 与 Live transcription 指南确认参数要求。

- **Genie 4 GA**
  - 模型：`models/genie-4`，通过 **Interactions API（v1beta）**提供实时交互式世界生成。
  - 支持通过 WebRTC 和 WebSockets 流式输出 16:9、24 fps 视频，以及同步 48 kHz 立体声音频；可由文本、16:9 参考图像或两者共同启动，并通过方向键 / WASD 或会话中的文本事件实时控制。
  - 定价：输入 **$1.50 / 1M tokens**、文本输出 **$9.00 / 1M tokens**、视频输出 **$17.50**；具体计费单位和完整费用规则应以官方价格文档为准。

### 其他公告

Gemini Tasks 在六个国家免费开放，并开始加强与 Google Workspace 的集成。Gemini App 也扩展到低内存 Android 设备，支持 Gemini Live 和自定义图像创建。这些是消费者产品公告，不代表相应能力已通过 API 开放。

### 开发者建议

1. **对 Neon 按 thinking level 做成本分层**：low / medium 可用于常规任务，高档位用于高难推理；重点测量质量、延迟和实际 token 消耗，不要只比较 Intelligence Index。
2. **评估 Tool Retrieval 是否能压缩 Agent 上下文**：用现有工具集测试检索准确率、漏选率、延迟和 token 节省，并在预览期为工具调用失败准备回退路径。
3. **把 Genie 4 作为新的实时多模态接入路径评估**：先验证 Interactions API 的 Beta 稳定性、WebRTC / WebSocket 连接管理，以及视频、文本和音频各自的计费边界。
4. **为转录编辑能力补充输入测试**：覆盖带原文和无原文、口语填充词、格式约束及实时会话中途编辑等场景。

### 第三方评测

Artificial Analysis 对 Gemini 4 Neon 给出的 Intelligence Index 为 **Low 44、Medium 55、High 60、Xhigh 61**，并报告其相较 Gemini 4 Carbon 的单位任务成本约低 17%。Google 另有 Gemini 4 Argon（Medium）评测分数 **48**。这部分属于第三方评测信息，本周未检测到 Argon 的官方 API 发布公告。
